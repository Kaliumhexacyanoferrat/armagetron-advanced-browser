A browser version of Armagetron Advanced (WebGL) hosted on this lambda, with multiplayer over websockets. The feeling should be very close to the original game. Any user can create a server; all servers are hosted on this single lambda. The user who creates a server is its admin and only they can control it, kick and ban people. There is a chat in the game. The multiplayer experience should be easy and nice, with a small starting page.
